# awwwards_project

Portfolio de Khadidja Ait Si Ali, développeur frontend & créatif freelance.

🔗 [khadidja-dev.fr](https://khadidja-dev.fr/)

## Stack

- HTML, CSS et JavaScript, sans framework ni étape de build
- [GSAP](https://gsap.com/) et ScrollTrigger pour toutes les animations (intro, scroll, interactions)
- [Magic Mouse](https://magicmousejs.web.app/) pour le curseur personnalisé
- [Formspree](https://formspree.io/) pour l'envoi du formulaire de contact
- Google Analytics, chargé uniquement après consentement

## Structure

```
index.html      page principale
notice.html     mentions légales
js/script.js    animations, retour en haut, formulaire, consentement cookies
styles/         main.css (base), styles.css (sections), notice.css
shared/         images et icônes
fonts/          polices locales
```

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
npx serve .
```
